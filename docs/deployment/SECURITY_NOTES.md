# Заметки по безопасности

## Friend-only модель

- Открытой саморегистрации в приложении нет: учётные записи создаются владельцем инстанса (скрипт `scripts/create_user.py` и аналоги).
- Роль и флаг активности задаются в базе (`admin` / `learner`, `is_active`); отключённые пользователи не проходят аутентификацию по паролю.
- Не смешивайте «друзей» и публичный интернет без осознанного решения; при `APP_MODE=public` или `ENABLE_PUBLIC_MODE=true` при старте пишется предупреждение в лог.

## Терминал и доверенный хост

- При `ENABLE_TERMINAL=true` команды выполняются **на машине приложения**, в ограниченной политике сервиса терминала, но **не в изоляции типа контейнерного sandbox** для произвольного кода студента уровня публичного judge.
- Краткая продуктовая рамка описана в [../product/TERMINAL_READINESS.md](../product/TERMINAL_READINESS.md).
- Включайте терминал только на **VPS, которым вы доверяете**, с доступом ограниченным по сети (VPN / SSH-туннель / whitelist друзей).

## Сессии и cookie

- `SessionMiddleware` Starlette ставит для cookie параметр **HttpOnly** по умолчанию — JavaScript страницы не читает токен сессии напрямую.
- **`Secure`** (только HTTPS) включается через `PERSONAL_LMS_SESSION_COOKIE_SECURE=true`; при HTTP-браузер не отправит cookie — это ожидаемо после перехода на HTTPS за reverse proxy.

## SQLite и секреты

- Файл БД нужно хранить в каталоге с правами только для пользователя сервиса; не включайте `instance/` в публичные бэкапы без шифрования, если есть чувствительные данные.
- `SESSION_SECRET_KEY` и ключи API хранятся только в переменных окружения или защищённом `.env`, не коммитьте их в Git.

## Инфраструктура

- Используйте межсетевой экран: приложение слушает `127.0.0.1`, наружу открыт только reverse proxy по 443 (или ваш приватный порт).
