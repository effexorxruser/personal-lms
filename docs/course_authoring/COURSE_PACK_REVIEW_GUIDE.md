# Course pack: ручной review перед принятием

Используйте этот список **после** того, как `scripts/check_course_pack.py` вернёт `0`. Он дополняет автоматический preflight качеством, контрактами и здравым смыслом.

## Содержательное качество и источники

- У каждого урока осмысленные блоки секций по контракту (см. `COURSE_PACK_CONTRACT.md`).
- `source_ids` в front matter действительно существуют в `source_registry.yml` после импорта (если в паке нет своего registry — имеется в виду целевая версия приложения).

## Связность графа (глазами человека)

- Ссылки между модулями, уроками и глобальными ресурсами читаются логически последовательно.
- Отсутствуют случайные дубликаты `lesson.key`, slug курсов с «похожими» именами но разным содержимым там, где ожидалась одна дорожка.

## Без побочных эффектов для runtime

- Нет ожиданий, что LMS прочитает `pack.manifest.yml` или любые временные экспортные только поля YAML.
- В пакете нет необходимости менять приложение или мигрировать схему БД только ради содержания курса.

## После утверждения

Фиксируйте результат в коде через обычный PR в `content/` согласно процессам репозитория или выбранному workflow переноса файлов.

Дополнительно: см. операции и ограничения в [`COURSE_PACK_OPERATIONS.md`](COURSE_PACK_OPERATIONS.md).
